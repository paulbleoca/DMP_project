# DMP_project

Idea : Plant Health Monitor

It makes uses of multiple sensors, each measuring useful information about the quality of a plant's environment.
What I have been thinking of is 2 main sensors / sensor groups, one to  measure the "outside" quality, such as light levels and air pressure.
The other would be inside the soil, measuring the soils' humidity, temperature, which will hint if the plant needs to be watered or warmed.

Some sort of alarm system will be implemented, such as LEDs and messages to an application connected by wifi.
For this im looking to use an ESP32 board due to its build in wifi.
